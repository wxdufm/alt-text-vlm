# Project context

## Scope
We aim to create a repository of text alternatives for existing album cover artworks, to enhance the experience of low-vision and blind people who are digitally engaging with music. Ultimately, the repository should serve as a flexible and open-source reference for various applications/use cases, such as in album review publications, on now-playing interfaces, and more. As a result, the alt text should be generated to stand alone, in the context of the musical release and its metadata (such as artist name, album name, etc.), but not tied to a specific use case. The golden rule is that all alt-text generated through this project should conform to the accessibility standard WCAG 2.2 (Web Content Accessibility Guidelines), specifically 1.1.1 Non-text Content. Generators should be aware of other web accessibility guidelines such as ATAG 2.0 (Authoring Tool Accessibility Guidelines) and implementation constraints (HTML <alt> tags). The final database should be straightforward to integrate with existing music metadata services, especially MusicBrainz and Discogs.
## Methodology
### Stage 1: Generating a training dataset
Firstly, we aim to use an existing open-source VLM (Vision Language Model) such as Qwen3-VL-8B or Gemma 4 31B to generate a training dataset of 500 album cover-alt text pairs using a subset of WXDU's releases database. We will generate a database of 500, since modesls usually need at least 300 high-quality samples to show some specialization. 500 provides a meaningful buffer over this number and is more manageable for a human to vet than anything larger. We will begin with small-scale comparisons of the two models to identify which produces more desirable alt text descriptions, before selecting one to generate the full 500. This generation will occur locally on an M4 Mac Mini through Ollama. Each pair will be human-verified with WCAG in mind.
### Stage 2: Fine-tuning a VLM model
Next, we will fine-tune a Qwen2.5-VL-7B or Gemma 4 E4B model (which one is still being decided) against the training dataset, again on the Mac Mini through Ollama. We will leave about 10-20% of the data as test for the fine-tuned model. Fine-tuned models should generate, in at least 95% of cases, alt text that conforms to this style guide and passes human verification.
### Stage 3: Large-scale alt text generation
Lastly, we will deploy our fine-tuned model to generate alt text on large sets of album covers. The first batch will be albums in the WXDU database which have an associated Discogs ID (around 50000 images). Stability is preferred over speed.
